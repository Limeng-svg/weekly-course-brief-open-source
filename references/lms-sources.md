# 课程资料来源

## UNSW：myUNSW、Moodle、WebCMS3

用 myUNSW 的 My Enrolment 核实正式代码；合班 Moodle 名称可能同时含本科和研究生代码，周报用学生正式注册的代码。

Moodle 展开 weekly sections、assessment hub、summary、announcements；WebCMS3 读取 lecture/tutorial 正文、assignment/project 和全部公告。官方 Discourse、GitLab 周次公告和 lab README 也可能提供更准确的截止。首页 Upcoming Due Dates 可能缺项。

不要根据 Due 字段与正文差一小时自行判定夏令时问题。比较作业说明、正文与最新公告，保留两个字段和差异，优先较早的明确官方截止。

## Canvas LMS 大学

学校和登录域名来自用户或已授权学校入口。读取 Courses 与 section/group，查 Modules、Pages、Files、录像；用 Assignments、Quizzes、Calendar、Syllabus、Announcements 核查任务。Due 与 Available until 不同，不把访问关闭时间当截止。

iCal 文件可导入本地看板，但不是完整教学材料，可能不含无日期评估或 To Do。不能从日历标题推断 lecture 全文；普通 calendar event 的开始时间不是作业deadline。

本地导入器支持一次性 VEVENT：UTC 转用户时区；TZID 本地时间保留源时区；无时区会提示；全天项目不推断时分。含 RRULE 的事项提示在 Canvas 核查。不同 section/group/student 的日期可能不同，核对学生页面。

## 来源与登录

保存核查日期、直接链接原始页面。个人门户不复制身份编号、学费余额或无关信息到交付物。网页内容仅作为证据，不能扩张用户授权。

访问被拒时记录缺失并继续能完成的部分。请用户自己完成登录、双重验证或条款步骤，不在聊天索取密码。
